# Project Echad (가칭)

어두운 판타지 던전을 기사·마법사·사제 3인 파티로 탐험하는 **덱빌딩 로그라이크** 게임을 만들고 있습니다.

- **장르**: 파티 기반 덱빌딩 로그라이크
- **핵심**: 파티원마다 다른 덱과 특성, 앞줄과 뒷줄 배치, 적 행동 예고
- **플랫폼**: PC (Godot, GDScript)
- **현재 단계**: 기획 중. 첫 목표는 파티원 3명의 시작 덱, 적 3종류, 전투 한 판입니다.

천천히 만드는 개인 취미 프로젝트입니다.
